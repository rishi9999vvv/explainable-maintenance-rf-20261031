# Dataset provenance and license

Original file: `ai4i2020.csv` in the public UCI download archive.

Dataset: AI4I 2020 Predictive Maintenance Dataset (2020).

Repository: UCI Machine Learning Repository, dataset 601.

DOI: https://doi.org/10.24432/C5HS5C

Source: https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset

Download: https://archive.ics.uci.edu/static/public/601/ai4i+2020+predictive+maintenance+dataset.zip

License: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/

The CSV is redistributed unchanged. It is a synthetic benchmark designed to reflect industrial maintenance data. It does not contain validated future-failure timestamps or remaining-useful-life targets. The generated audit in `results/metrics.json` records the downloaded file's SHA-256 digest, row counts, exclusions, split counts and target/flag inconsistencies. `download_data.py` can fetch the public source again.
